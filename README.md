## Задание 1: Юнит-тесты
### Автотесты для проверки программы, которая помогает заказать бургер в Stellar Burgers

### Реализованные сценарии
Созданы юнит-тесты, покрывающие класс `Burger`
Процент покрытия 100% (отчет: `htmlcov/index.html`)

### Структура проекта
- `praktikum` - пакет, содержащий код программы
- `tests` - пакет, содержащий тесты

### Запуск автотестов
**Установка зависимостей**
> `$ pip install -r requirements.txt`

**Запуск автотестов и создание HTML-отчета о покрытии**
>  `$ pytest --cov=praktikum --cov-report=html`

## Юнит-тесты, покрывающие класс `Burger` - test_burger.py
- **`test_add_bun`** - добавляем булочку
- **`test_changing_bun`** - меняем ранее добавленную булочку
- **`test_add_one_ingredient`** - добавляем 1 ингредиент
- **`test_add_two_same_ingredients`** - добавляем 2 одинаковых ингредиента
- **`test_add_two_different_ingredients`** - добавляем 2 разных ингредиента
- **`test_remove_only_ingredient`** - удаляем 1 единственный ингериент
- **`test_remove_ingredient`** - удаляем ингериенты из списка (тест с параметризацией)
- **`test_move_ingredient`** - меняем ингериенты в списке местами (тест с параметризацией)
- **`test_get_price`** - узанем цену бургера (тест с параметризацией)
- **`test_get_receipt_without_ingredients`** - получаем чек на бургер без ингредиентов (только булочки)
- **`test_get_receipt_burger_with_ingredients`** - получаем чек на бургер с ингредиентами
